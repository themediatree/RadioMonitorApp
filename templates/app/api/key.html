Schedule windows

Pass schedule_windows on any POST endpoint to register broadcast or monitoring time windows. Detections outside these windows will be flagged out_of_schedule: true in GET responses — the same out-of-spot logic applied on the dashboard. 

schedule_windows=[{"day": -1, "from": "06:00", "to": "18:00"}]

day: -1 = all days, 0 = Monday … 6 = Sunday. Multiple windows can be supplied in the array (e.g. different hours per day). Omit schedule_windows to register without a time restriction — all detections will be considered in-schedule.

All endpoints return JSON. Clip/audio URLs in responses are signed and valid for 1 hour. Rate limit: 100 requests/minute.
